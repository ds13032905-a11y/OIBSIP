To-Do Web App
Description

A simple and responsive To-Do Web App developed using HTML, CSS, and JavaScript. It helps users manage daily tasks with separate Pending and Completed task lists.

Features
Add New Tasks
Pending Tasks List
Completed Tasks List
Mark Task as Complete
Inline Task Editing
Delete Tasks
Pending Task Count
Completed Task Count
Timestamp Display
Local Storage Support
Empty State Messaging
Responsive Design
Technologies Used
HTML5
CSS3
JavaScript
Local Storage
