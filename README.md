# Login Authentication System

## Description

This is a simple and secure Login Authentication System developed using HTML, CSS, and JavaScript. The application allows users to register with a username, email, and password, login using valid credentials, access a protected dashboard, and logout securely. Passwords are protected using SHA-256 hashing and are not stored in plain text.

## Features

- User Registration
- Username Validation
- Email Validation
- Password Validation
- Minimum 8 Character Password
- At Least One Number in Password
- Duplicate Email Detection
- Secure SHA-256 Password Hashing
- User Login Authentication
- Invalid Credential Error Message
- Protected Dashboard
- Logout Functionality
- Local Storage Support
- Form Validation
- Responsive Layout
- Clean and Simple User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Web Crypto API
- SHA-256
