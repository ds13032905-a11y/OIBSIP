# Tribute Page – Dr. A.P.J. Abdul Kalam

## Description
This is a simple and responsive Tribute Page dedicated to Dr. A.P.J. Abdul Kalam, the "Missile Man of India" and the 11th President of India. The page highlights his life, achievements, and an inspiring quote using HTML and CSS.

## Features
- Biography of Dr. A.P.J. Abdul Kalam
- Achievements Section
- Famous Quote
- Responsive Layout
- Clean and Simple User Interface

## Technologies Used
- HTML5
- CSS3
